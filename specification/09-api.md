# 09 — API

Most CRUD goes through Supabase directly (RLS) from server components / server actions. Custom
HTTP endpoints exist where server-side orchestration or secrets are needed. All request/response
bodies are defined as zod schemas in `packages/shared/contracts/*` and imported by both sides.

Errors: `{ error: { code: string, message: string, details?: unknown } }` with proper HTTP status
(400 validation, 401, 403, 404, 409 conflict, 422 business rule, 500).

## 1. Web app (Next.js route handlers / server actions)

| Method & path | Purpose | Role |
|---------------|---------|------|
| `POST /api/projects` | create project (+ default viewport) | platform admin |
| `POST /api/projects/import-env` | parse `.env` text → preview (no write) | platform admin |
| `POST /api/projects/:id/check-bucket` | F-PROJ-5 | project admin |
| `POST /api/projects/:id/sitemap` | start snapshot | editor+ |
| `POST /api/projects/:id/runs` | body `{snapshotId, viewports[], scope, urls?, sample?, note?, dryRun?}` → `{runId, label}` or dry-run item list | editor+ |
| `POST /api/runs/:id/cancel` · `/retry-failed` | | editor+ |
| `POST /api/runs/:id/baseline` | set baseline | editor+ |
| `DELETE /api/runs/:id` | → `{ deleting: {comparisons:[…], objects:n} }`; requires `?confirm=true` | project admin |
| `POST /api/projects/:id/import-legacy` | list or import legacy prefixes | project admin |
| `POST /api/projects/:id/comparisons` | `{beforeRunId, afterRunId, replace?}` | editor+ |
| `POST /api/comparisons/:id/review` | `{itemIds[], review, note?}` (calls RPC `review_items`) | editor+ |
| `POST /api/comparisons/:id/rediff` | re-run with current rules | editor+ |
| `POST /api/comparisons/:id/share` · `DELETE …/share` | create/revoke link `{expiresInDays}` → `{url}` | editor+ |
| `GET /api/comparisons/:id/export.html` | static report download | viewer+ |
| `GET /api/r2/sign?key=…&comparison=…` | short-lived signed GET URL for an object of a project the user can view (or share token) | viewer+ / share |
| `POST /api/projects/:id/storage/refresh` | | project admin |
| `POST /api/notifications/:channelId/test` | | project admin |
| `POST /api/invitations` · `DELETE /api/invitations/:id` | | project admin / platform admin |

Image URLs: if `r2_public_url` set → `${r2_public_url}/${key}`; else signed URL (TTL 1 h)
generated by the web server with the S3 credentials. Signing endpoint validates that the key
belongs to the project's bucket and a run/comparison of that project.

## 2. Worker HTTP API (HMAC-signed, called only by web)

| Method & path | Body | Result |
|---------------|------|--------|
| `POST /jobs/sitemap` | `{snapshotId}` | `{workflowId}` |
| `POST /jobs/capture` | `{runId}` | `{workflowId}` |
| `POST /jobs/capture/:runId/cancel` | — | `202` |
| `POST /jobs/compare` | `{comparisonId}` | `{workflowId}` |
| `POST /jobs/delete` | `{entity: 'run'|'comparison'|'project', id}` | `{workflowId}` |
| `POST /jobs/import-legacy` | `{projectId, labels[]}` | `{workflowId}` |
| `POST /jobs/storage` | `{projectId}` | `{workflowId}` |
| `GET /jobs/:workflowId` | — | Workflow status passthrough |
| `GET /health` | — | `{ok, version}` (unsigned) |

The worker re-reads all state from Supabase by id — request bodies carry ids only, never settings
or secrets.

## 4. Container API

`POST /diff` (bearer) — body:
```json
{ "bucket": "…", "beforeKey": "…", "afterKey": "…", "diffKey": "…",
  "threshold": 0.1, "changeThresholdPct": 0.05,
  "regions": [{"x":0,"y":0,"width":1280,"height":80}] }
```
→ `{ "changed": true, "diffPct": 1.23, "diffPixels": 12345, "totalPixels": 1000000, "beforeDims": [1280, 5000], "afterDims": [1280, 5100], "afterSha256": "…" }`

## 5. Database RPCs

* `review_items(p_comparison_id uuid, p_item_ids uuid[], p_review review_status, p_note text)` — checks `can_edit`, updates rows, writes `review_memory` and audit, refreshes `review_counts`.
* `refresh_run_counts(p_run_id)`, `refresh_comparison_counts(p_id)` — service role.
* `set_baseline(p_project_id, p_run_id)` — checks `can_edit`, run completed*, audit.
* `resolve_share_token(p_token text)` — security definer; returns comparison id if hash matches and not expired.
